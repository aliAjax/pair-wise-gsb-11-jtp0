# 油站巡检标准与异常复核台

- 行业：石油
- 技术栈：React 19、Vite、TypeScript（零新增依赖，未引入组件库）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则验证：`npm run verify`（36 条业务断言 + 刷新持久化一致性验证）

数据保存在浏览器 localStorage（key：`dfwlfront-10-inspection-standards-v1`），页面右上角可一键恢复演示数据。

## 功能闭环

1. **标准版本（管理员）**：按区域发布检查模板，登记必检设备、允许范围（数值闭区间或选择期望项）和生效时间窗口。
   - 同区域已发布模板的生效窗口不得重叠（半开区间，首尾相接允许）。
   - 区域内存在未闭环异常时只能保存草稿；结构校验、窗口重叠、异常闸门实时提示。
   - 已发布版本不可改、不可删；改版基于旧版创建新版草稿，版本号按区域递增。
2. **巡检填报**：按巡检时间匹配当时生效的模板，现场读数实时判定（数值越界 / 选择项不符即异常），异常必须填写说明。
   - 提交时把模板整体**冻结为快照**内嵌进记录（模板编号、版本、允许范围逐台复制）；之后标准改版，旧记录仍按旧快照展示，**不重新判定**。
3. **巡检记录**：以表格展示冻结版本与逐项判定，可对任意设备发起抽检。
4. **异常复核台**：
   - 抽检按原记录冻结的范围重新判定；结论偏离原记录（正常⇄异常）时自动生成复核任务，同一设备不可重复抽检。
   - 复核人**必须与原巡检人不同**，提交复核结论时连同异常一起闭环；非抽检类异常由责任人登记整改闭环。
   - 异常台账未闭环数量直接决定同区域新标准能否发布。

## 分层结构

标准资料、判定、本地存储与页面各自独立，互不反向依赖：

```
src/
├── domain/
│   ├── types.ts     # 领域模型：模板 / 冻结快照 / 巡检 / 异常 / 抽检 / 复核
│   ├── catalog.ts   # 标准资料：区域与设备目录、出厂允许范围（可替换为接口数据源）
│   └── rules.ts     # 判定规则：范围判定、窗口重叠、发布闸门、模板冻结（纯函数）
├── storage/
│   ├── time.ts      # ISO 与 datetime-local 转换
│   ├── seed.ts      # 首启演示数据（快照由 freezeTemplate 构建，保证一致）
│   └── store.ts     # localStorage 持久化 + useSyncExternalStore + 全部写操作
├── pages/
│   ├── TemplatesPage.tsx    # 管理员：模板草稿 / 发布 / 版本列表
│   ├── InspectionPage.tsx   # 巡检填报（实时判定，提交冻结）
│   ├── RecordsPage.tsx      # 记录与冻结快照、抽检入口
│   ├── ReviewStation.tsx    # 抽检登记 / 复核任务 / 异常台账
│   └── components.tsx       # 纯展示组件
└── App.tsx                  # 导航、指标与页面编排
```
