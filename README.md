# 油站巡检标准版本与异常复核台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据保存在浏览器 localStorage（单键整体读写），刷新后模板、巡检快照、复核任务保持一致；未引入任何新依赖。

## 功能与规则

### 巡检标准版本
- 管理员按区域发布检查模板，登记必检设备、允许范围（数值下限/上限 或 选择项）与生效窗口。
- 同一区域已发布模板的生效窗口不得重叠。
- 区域内存在未闭环异常时，模板只能保存草稿（页面直接展示阻塞原因）。
- 已生效模板不可修改，可一键基于它新建版本（同名同区域版本号自动递增，新窗口默认衔接旧窗口次日）。

### 巡检填报
- 按区域与巡检时间自动匹配生效窗口内的模板；必检项必须填写，数值/选项实时判定。
- 提交时冻结模板版本与判定标准（记录内置 frozen 快照），旧记录不随新标准重算。

### 异常复核台
- 记录按提交时的模板快照展示；异常可登记闭环人与处理说明。
- 对原记录做抽检：判定结论偏离（正常↔异常）或数值偏离时，自动生成复核任务；未偏离不生成。
- 复核人必须与原巡检人不同，否则无法完成复核。

## 分层结构

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 标准资料 | `src/domain/standards.ts` | 区域、人员、种子模板/记录/复核任务等纯数据 |
| 领域判定 | `src/domain/rules.ts` | 窗口重叠、发布阻塞、范围判定、快照构建、抽检偏离、复核校验 |
| 模型 | `src/domain/types.ts` | 模板、巡检记录、复核任务类型 |
| 本地存储 | `src/domain/storage.ts` | localStorage 单键整体读写、版本校验、种子回落 |
| 状态 | `src/store/useStore.ts` | Zustand 动作封装，每次变更整体落盘 |
| 页面 | `src/ui/StandardsPage.tsx`、`InspectPage.tsx`、`ReviewPage.tsx` | 三个功能页，不含判定逻辑 |

存储键：`dfwlfront-10-inspection-standard-v2`。
